# 🎮 ECII - Jueguin de Plataformas

**ECII** es un juego de plataformas desarrollado en lenguaje ensamblador **Z80**, diseñado para funcionar en sistemas con recursos limitados. El objetivo principal es esquivar obstáculos mientras se avanza por niveles desafiantes.

## 🚀 Características

- **Gráficos en 2D**: Representación visual utilizando gráficos de píxeles.
- **Movimiento fluido**: Control del jugador con respuesta en tiempo real.
- **Obstáculos dinámicos**: Elementos que se mueven y cambian durante el juego.
- **Niveles progresivos**: Aumento de dificultad conforme se avanza.
- **Sonido básico**: Efectos sonoros para mejorar la experiencia.

## 🛠️ Tecnologías Utilizadas

- **Lenguaje**: Ensamblador Z80
- **Herramientas**: Emuladores y compiladores compatibles con Z80
- **Recursos**: Gráficos en formato binario y texto

## 📁 Estructura del Proyecto

- `README.md`: Este archivo de documentación.
- `*.X68`: Archivos de código fuente en ensamblador.
- `datos_pixeles.bin`: Datos gráficos en formato binario.
- `datospers.txt`: Información de configuración y parámetros del juego.
